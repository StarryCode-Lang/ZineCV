# 更新记录

本文件记录面向维护者和使用者的可见变化。未发布的改动放在 `Unreleased`，具体版本发布时再建立版本条目。

## [Unreleased]

- 移除“版式风格”预设入口及其动效、样式；格式面板保留颜色、日期、对齐等实际可编辑选项。版本分支弹窗统一为浅色主题，修正收起时重复动画造成的闪烁，并清理旧历史列表的无引用样式。
- 导入侧栏模板时沿用原件识别到的背景色，并自动选择深色或浅色文字；粉白 PDF 的内容编辑、刷新保留及 PNG 导出已实测。
- 右侧纸张按可用宽度调整默认缩放，宽屏预留竖排 RESUME 背景空间；分栏拖动范围随窗口宽度调整，背景文字固定在背景板。
- 整理项目入口：GitHub 协作文件移入 `.github/`，更新记录移入 `docs/`，生成式架构图改由 CI 工件交付；移除未使用的版本图包装和草稿保存分支。
- 浏览器回归通过时只保留精简结果，失败时保存截图证据，减少 `.artifacts` 反复累积。
- 将简历版本历史和分支图统一为同一张提交关系图，模板重命名会同步到各历史节点。
- 统一编辑模块折叠、拖拽和浮层反馈的 Motion 交互，并修正预览标题与 A4 纸张左边界的对齐。
- 首次打开使用空白简历；保留本机草稿和版本库，不把个人简历示例随公开源码发布。
- 每次 GitHub 推送后自动刷新 GitNexus 索引、运行 ast-grep 扫描并交付当前提交的 Archify 图工件。
- 明确仓库清理清单：保留必要工具入口、协作/许可文档、独立回归脚本及固定验收证据；清除已核对的可重建缓存与临时截图。
- 合并使用、架构、版本存储、维护状态和第三方素材说明，移除已完成的阶段性计划/迁移文档。
- 模板库、版本管理和 AI 辅助工作区改为按需加载；生产首屏 JavaScript 从 552 KB 降至 508 KB（gzip 从 174 KB 降至 160 KB），A4 预览仍即时加载。
- 增加 Archify 高层架构源规格和交互式架构图，覆盖编辑器、预览、分页、导出、版本管理与回归测试。
- 增加 MIT 源代码许可证、资产说明、贡献指南、安全策略、行为准则和 GitHub Issue/PR 模板。
- 移除未被源码引用且含示例简历个人信息的旧参考截图和审计截图。
