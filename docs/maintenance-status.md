## 当前实现

- 左侧编辑、右侧固定 A4 预览；支持基本信息、富文本经历、模块管理、分栏拖动、智能一页、PDF/PNG 导出和可视化版本历史。
- 模板库支持本地图片、PDF 和 DOCX 导入。文件先由用户确认是否识别，识别结果在浏览器中映射到受控编辑字段，原始文件不上传网络。PDF 导入的首屏在 A4 纸张上显示第一页源图像；开始编辑后去掉源图像，展示与编辑状态同步的预览。
- 导入模板支持收藏和最近使用筛选，刷新后保留；最近使用只在应用模板时记录。此元数据独立保存在浏览器，不进入简历正文、版本快照或项目 `.data`。
- 原版、清晰单栏和紧凑单栏是顶部“格式”；导入的侧栏型简历只在显式模板样式下使用独立版式。
- 智能一页在刷新、窗口/网页缩放、格式切换和模板应用时自动运行；正文编辑后退出智能状态，用户手动触发时才显示进度提示。无法安全压缩时保留多页。
- 顶部与章节浮层支持边缘避让、点击外部关闭、Esc 和焦点返回；系统开启减少动态效果时停止持续位移和旋转。
- 左侧基本信息和自我评价默认收起，其余大模块默认展开；每组经历一次展开一项，组与组之间互不收起。模块拖拽使用固定起始矩形、逐帧 ghost 和 FLIP 让位，松手后一次性提交顺序；预览轮廓在纸张外层绘制，不参与分页、打印或导出。
- 版本历史和分支图共享同一份提交图，支持提交、分支、恢复和删除；项目文件写入失败时保留原文件并提示，不创建空版本库。
- 常驻助手在编辑、模板和版本页面共享当前会话，并可切换浏览器本地历史会话，包含 composer、chat、Bot 三种模式。窗口可拖动，底右锚点保存在浏览器本地，切页与刷新后恢复；首次绘制即使用目标位置，输入区固定在面板底部。项目专用 Harness 支持用户明确选择上下文、本地技能、取消生成、待确认提议和状态变化校验；没有接入任何外部 Agent。模型调用可由用户配置 OpenAI-compatible API；设置页可读取服务模型列表、显示数量并按模型 ID 前缀提示。API Key 仅保存在本地服务进程内存，模型列表只保留在当前设置会话。云同步、账号、模板市场和文本型 PDF 导出不属于当前范围。
