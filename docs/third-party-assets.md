## 使用规则

1. 修改或替换 `public/fonts/` 前先记录来源、版本、SHA-256 和许可证；字体变更会影响 A4、分页和导出，必须重新跑预览回归。
2. 公开截图使用虚构 fixture，彻底排除真实姓名、联系方式、头像、浏览器存储和 `.data`。
3. 依赖许可证只覆盖对应依赖，不把 `package-lock.json` 或 `node_modules` 当作项目授权证明。
4. 下游打包或部署前重新核查四个字体文件。若无法补齐证据，应替换为来源明确的字体，或把字体作为用户本地资源而不随发布包分发。
5. 文档中的 `UNKNOWN` 是待核实状态，不是授权许可，也不能被 CI 结果自动提升为“已批准”。

## 验证入口

- `npm run test:release-docs`：检查本文件、项目许可证、保护文件和发布边界。
- `node scripts/privacy-release-regression.cjs`：构建后用独立浏览器检查空白预览和已有本地草稿恢复；同时检查公开默认字段、被跟踪的用户版本数据与文档图片。
- `npm run check`：检查源码、格式和生产构建。
- `npm run test:preview`：核对固定 A4 内容、字体和导出契约。

本次仓库整理只更新文档和公开项目元数据；不修改用户版本数据、固定预览基线或字体内容。用户版本数据仍不进入 GitHub。
