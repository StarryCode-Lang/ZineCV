## 2. 产品与架构边界

Tauri 2 + React + Rust/Typst + SQLite 本地简历编辑器。正式 UI 位于 `src/ui`（默认预览为 DOM 渲染）；`src/preview/` 的引擎 SVG/TextMap/链接/选字/RTL 消费组件独立保留（受几何门禁约束，不因"未默认"删除）；`src/platform/` 是前端 IPC 与数据转换边界。

| 入口 | 职责 |
| --- | --- |
| src/main-desktop.tsx → src/ui/app/App.tsx | 编辑/DOM预览/模板/版本/Agent 接线 |
| src/ui/agent/ | AgentOverlay（悬浮层/会话/提案）+ context（引用目录/预算）+ agentToolSchemas（工具 JSON Schema）+ agentOverlayUtils（纯函数）+ stream（原生通道流式）+ sessions（800ms 去抖落盘） |
| src/platform/ | 类型化 IPC、NativeDocumentClient、持久化、版本、设置、旧数据导入、字体协议 |
| src-tauri/src/lib.rs 等 | 56 个业务 IPC；storage/migration（SQLite 迁移 17，仅追加）；identity/gateway/agent；render_worker/render_scheduler；领域 schema/逻辑已抽至 `crates/zinecv-{contracts,domain}`（经 `src-tauri/src/domain.rs` 再出口垫片引用） |
| src-tauri/src/engine.rs + engine/ | 三模板冻结排版、TextMap/HitRegion、一页求解、统一 PDF/PNG 导出（ExportProduct 按需，64MiB 解码上限，原生写盘故障映射） |
| src-tauri/examples/ | typst_poc.rs 与 engine_render.rs 是两个受保护引擎验证程序的源（visual-parity / engine-parity 消费其产物） |

106 个 `src-tauri/src/domain/bindings/` 类型由 ts-rs 生成不手改（生成源为 `crates/zinecv-contracts`）；56 个 IPC 与 handler/capabilities/公共契约三方一致由 `verify:contracts` 强校验。

统一导出从冻结修订调用 `render_document_export`；字体为引擎内嵌字节经只读 `zinecv-font` 协议共享，浏览器 fixture 用 public 字体；release 构建由包装器设 `ZINECV_RELEASE_FONTS=engine` 去重。历史版本图全量保留、快照按需物化（上限 1000 含 head）。

## 3. 构建、运行与实测时长

Node `>=24 <25`；Rust≥1.88；Windows + MSVC Build Tools；`npm ci` 复现锁依赖。所有原生编译经 `tools/with-msvc.ps1`（npm 脚本已封装）。

| 目的 | 入口 |
| --- | --- |
| 日常完整桌面开发 | `npm run dev` |
| 构建正式宿主 / 测试宿主 | `npm run build:native` / `npm run build:native-hooks` |
| Windows 安装器 | `npm run package:windows`（在线 NSIS） |
| 原生检查/测试/绑定 | `check:native` / `test:native` / `test:native-hooks` / `test:bindings` |
| 套件 | `node tools/verify-project.mjs --suite fast\|regression\|full`（34 阶段用 `--plan` 查看） |

**从零重建实测**（2026-10-06）：check/test/bindings ≈15 分钟；release（fat LTO 单 CGU）≈39 分钟；hooks profile ≈47 分钟；增量 no-op ≈1.5s。`.cargo/config.toml` 单 target 根、jobs=2。

硬约束（违反即翻车）：

- **构建收据拒绝"构建期间输入变化"**——cargo/vite 构建运行时不得改动仓库任何文件（含 docs/licenses、CSS 等一切 vite 输入），否则收据作废白等一轮。
- WebView2 套件与 bench/soak 串行、隔离 profile/SQLite；测试宿主保留 disable-backgrounding-occluded-windows 等三参数（rAF flush 依赖）。
- 新 IPC 同步 domain 枚举、handler、capability、契约、绑定五处；重生绑定后看真实退出码。
- worker `Command::new` 可执行路径保持已验证安全形状；测试注入必须真实触发 Job Object 限制。
- 同源码 PE 的时间戳/CodeView 变化会改变 SHA；结论只绑定实际被测 exe 的哈希。
- SQLite `Store::open` 已带 SQLITE_BUSY/LOCKED/READONLY 有界重试（20×10ms，304 测试验证）。
- ts-rs 绑定导出经 with-msvc 的共享绝对 `TS_RS_EXPORT_DIR` 基准（contracts/src-tauri 双 crate 必需）；裸 `cargo test` 再生成会把跨 crate 相对导入写错层级。
