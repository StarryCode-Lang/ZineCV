## 2. 产品与架构边界

Tauri 2 + React + Rust/Typst + SQLite 本地简历编辑器。正式 UI 位于 `src/ui`（默认预览为 DOM 渲染）；`src/preview/` 的引擎 SVG/TextMap/链接/选字/RTL 消费组件独立保留（受几何门禁约束，不因"未默认"删除）；`src/platform/` 是前端 IPC 与数据转换边界。

| 入口 | 职责 |
| --- | --- |
| src/main-desktop.tsx → src/ui/app/App.tsx | 编辑/DOM预览/模板/版本/Agent 接线 |
| src/ui/agent/ | AgentOverlay（悬浮层/会话/提案）+ context（引用目录/预算）+ agentToolSchemas（工具 JSON Schema）+ agentOverlayUtils（纯函数）+ stream（原生通道流式）+ sessions（800ms 去抖落盘） |
| src/platform/ | 类型化 IPC、NativeDocumentClient、持久化、版本、设置、旧数据导入、字体协议 |
| src-tauri/src/lib.rs 等 | 56 个业务 IPC、窗口和能力装配、render_worker/render_scheduler、export_io、font_protocol；storage/identity/migration 与 agent/gateway/context 从 crate 再出口，无重复实现 |
| crates/zinecv-{contracts,domain}/ | 106 个单源契约、AppError、命令应用/CAS、校验和默认文档；domain.rs 仅再出口 |
| crates/zinecv-engine/ | 三模板冻结排版、TextMap/HitRegion、一页求解、统一 PDF/PNG 导出（ExportProduct 按需、64MiB 解码上限）；engine.rs 仅再出口 |
| crates/zinecv-storage/ | SQLite 迁移 17（仅追加）、Store/事务/版本图/提案/备份/旧数据导入/本机账户；秘密能力由宿主注入 |
| crates/zinecv-agent/ | Agent 策略、上下文与 Provider 协议；AgentTransport 可注入，NativeTransport 保留既有 HTTP/SSE 安全逻辑 |
| crates/zinecv-native/ | Windows Current-user DPAPI 的 SecretProvider 实现；密文字节与备份格式不变 |
| src-tauri/examples/ | typst_poc.rs 与 engine_render.rs 是两个受保护引擎验证程序的源（visual-parity / engine-parity 消费其产物） |
