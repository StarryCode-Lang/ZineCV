## 产品与架构入口

Tauri 2 + React + Rust/Typst + SQLite本地简历编辑器。正式UI默认DOM预览，SVG/TextMap组件受几何门禁保护。Agent调用所配置的模型服务；本地存储不等于模型请求离线。

| 入口 | 边界 |
| --- | --- |
| `src/main-desktop.tsx` → `src/ui/app/App.tsx` | 正式编辑、模板、DOM预览、版本及Agent装配 |
| `src/platform/` | 类型化IPC、权威文档客户端、持久化/版本/设置/迁移/字体协议 |
| `src/preview/` | 引擎SVG、TextMap选字、链接与RTL；不能因非默认而删除 |
| `src-tauri/src/lib.rs` 等 | 56业务IPC、窗口/能力、worker/scheduler/export_io/font_protocol |
| `crates/zinecv-{contracts,domain}/` | 106单源类型、AppError、命令/CAS、校验与默认文档 |
| `crates/zinecv-engine/` | 三模板冻结排版、TextMap/HitRegion、一页求解、PDF/PNG按需ExportProduct、64MiB解码上限 |
| `crates/zinecv-storage/` | SQLite schema17追加迁移、事务/版本图/提案/备份/旧数据及账户；秘密能力注入 |
| `crates/zinecv-agent/`、`zinecv-native/` | AgentTransport策略/Provider/SSE；Windows Current-user DPAPI SecretProvider |
| `src/main-web.tsx`、`src/platform/browser/`、`crates/zinecv-wasm/` | 共享Rust Core/React、Worker、OPFS SAH VFS、Web Lock、WebCrypto、CORS、下载/PWA |
| `crates/zinecv-ohos/` | 原生core/NAPI POC，非完整HarmonyOS宿主 |

当前已通过 Windows 开发构建、318项原生单元测试、83项前端/工具单元测试、106绑定类型与两次真实开发窗口启动检查；两次启动均未触发Rust编译，第二次约10秒。该结果不是完整资格或release交付。保留可持续开发环境，保留 node_modules、dist 与 src-tauri/target/debug 缓存；桌面和六个共享核心加轻量 assets crate 使用根 workspace/Cargo.lock，WASM/OHOS 保持独立发布配置与锁文件。存储从 assets 读取字体字节，engine 再出口兼容原路径；storage 的 PDF 集成测试仍以 dev-dependency 引用 engine。当前目录逻辑大小约6.64GiB，NTFS压缩并按文件身份去重后的文件数据占用约3.63GiB（不含文件系统目录元数据）。当前开发准备记录见 `.artifacts/analysis/development-ready.json`；后续变更会使该快照过期。具体开发入口与验证边界见 DEVELOPMENT_FEEDBACK。

后续需Node24、Rust≥1.88/MSVC；npm ci后npm run dev启动完整Tauri，不另设Vite预览。CSS用dev:css/check:css、隔离数据/核收据，非CSS变化拒绝复用；见`docs/DEVELOPMENT_FEEDBACK.md`。冷release约39分钟/hooks47分钟，缓存缺失不承诺五分钟，独立exe更新才按需构建。

原生经`tools/with-msvc.ps1`，单target/jobs=2，内存紧张可CARGO_BUILD_JOBS=1。构建期间不改任何仓库文件；Vite/crates/锁文件/编译器收据匹配才复用。ts-rs共享绝对TS_RS_EXPORT_DIR，裸cargo生成会错相对导入，文档注释变化也会漂移；核真实退出码。

WASM历史可用外部工具链为 `D:\tmp\llvm`（clang23.1.3）、`~/.cargo/bin/wasm-bindgen.exe`（0.2.129），需明确 `CC_wasm32_unknown_unknown` / `AR_wasm32_unknown_unknown` / `ZINECV_WASM_BINDGEN`；with-msvc旧Codex默认路径失效，复用前检查实际存在。build:web需HTTPS/localhost；备份对照先platform-reference并设ZINECV_BACKUP_NATIVE_PARITY=1。getrandom需wasm特性+wasm_js cfg。OHOS SDK缺失，build:ohos-core不可运行。

Bash的Windows PATH未转换：内部用POSIX路径，spawn npm/cargo经PowerShell并恢复原Windows PATH。两个verify-project/accept-project实例禁止并发；原生/WebView2/测量串行隔离；WebView2保留三项后台参数，动画点击/EPERM先排偶发。worker路径与Job Object注入约束见AGENTS。
