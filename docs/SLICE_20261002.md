## 产品与架构入口

Tauri 2 + React + Rust/Typst + SQLite本地简历编辑器。正式UI默认DOM预览，SVG/TextMap组件受几何门禁保护。Agent调用所配置的模型服务；本地存储不等于模型请求离线。

| 入口 | 边界 |
| --- | --- |
| `src/main-desktop.tsx` → `src/ui/app/App.tsx` | 正式编辑、模板、DOM预览、版本及Agent装配 |
| `src/platform/` | 类型化IPC、权威文档客户端、持久化/版本/设置/迁移/字体协议 |
| `src/preview/` | 引擎SVG、TextMap选字、链接与RTL；不能因非默认而删除 |
| `src-tauri/src/lib.rs` 等 | 62业务IPC、窗口/能力、worker/scheduler/export_io/font_protocol |
| `crates/zinecv-{contracts,domain}/` | 108单源类型、AppError、命令/CAS、校验与默认文档 |
| `crates/zinecv-engine/` | 三模板冻结排版、TextMap/HitRegion、一页求解、PDF/PNG按需ExportProduct、64MiB解码上限 |
| `crates/zinecv-storage/` | SQLite schema17追加迁移、事务/版本图/提案/备份/旧数据及账户；秘密能力注入 |
| `crates/zinecv-agent/`、`zinecv-native/` | AgentTransport策略/Provider/SSE；Windows Current-user DPAPI SecretProvider |
| `src/main-web.tsx`、`src/platform/browser/`、`crates/zinecv-wasm/` | 共享Rust Core/React、Worker、OPFS SAH VFS、Web Lock、WebCrypto、CORS、下载/PWA |
| `crates/zinecv-ohos/` | 原生core/NAPI POC，非完整HarmonyOS宿主 |
