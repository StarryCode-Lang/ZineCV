正式 UI 为 React/DOM 预览；`src/preview` 保留 SVG/TextMap 的选字、链接与 RTL 消费组件。Rust contracts 为类型和72个业务 IPC 的单一来源；SQLite schema18、CAS、事务、来源草稿和版本身份继续保护。架构见[决策](ARCHITECTURE_TARGET_CPLUS.md)，接口见[IPC 契约](public-ipc-contract-v1.md)。
