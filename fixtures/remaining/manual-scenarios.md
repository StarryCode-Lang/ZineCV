# R01 人工与原生验收输入

输入可编辑，不以历史SHA冻结。合成输入按`fixtures/remaining.mjs`逻辑名称读取；需文件时用`node fixtures/remaining.mjs --export documents/one-page.json .artifacts/runtime-tmp/one-page.json`单份导出，拒绝覆盖已有文件。以下17个场景是步骤与预期，不是人工验收通过记录。

2026-10-21范围更新：取消干净VM/外部测试机、代码签名证书及更新签名方案；REAL-MODEL-01与REPRO-01由用户自行负责，Agent不再执行或等待材料。安装生命周期、数据库兼容回退及许可保留；范围调整不记为验收通过。

## VIS-01 固定 UI / A4 对照

1. 以隔离 profile 和独立 `ZINECV_DATA_DIR` 启动当前正式 release WebView2；记录 exe SHA-256、应用构建、字体与资源哈希。
2. 导入 `one-page.json`、`two-pages.json` 和 `five-pages.json`，分别固定 `1440×900`、`1920×1080`、`1050×700` 视口；比较左编辑器外壳、右侧 A4 纸张尺寸/位置、分页与文字完整性。
3. 代表性组合覆盖 DPI `100/125/150/200%` 和预览缩放 `20/100/200%`，记录真实窗口截图的 DPR、分栏和滚动位置。
4. 当前应用完成上述采集后，才启动 `D:\Desktop\resume DIY` 的独立实例和独立 profile 做同输入/同视口对照。旧项目源码、`.data`、历史基线与用户当前 `5173` 页面保持不变。
5. 单独登记引擎三模板的关键块 pt 几何、断行、页数和文本提取；像素差异只作诊断。保留历史 `PREVIEW-01` 失败，不能重录或覆盖。

## IME-01 微软拼音与文本编辑（M）

1. 在 `richtext-cjk-latin-emoji-link-lists.json` 对应条目末尾开始空白编辑器，记录提交前 durable cursor。
2. 使用微软拼音输入一段中文，在候选列表未确认时观察编辑器、Agent 浮层和保存状态；选择候选并按 Enter 确认。
3. 重复测试取消候选、中文标点、`😀`、`e + U+0301` 组合字符及连续输入；每个场景分别记录 composition 期间的 DOM/选区和 compositionend 后的命令/修订。
4. composition 期间尝试弹层关闭、切换模块和正常关闭；若设计要求等待，应等待候选结束或明确阻止动作。不得用 Playwright `fill`、粘贴或英文键盘模拟代替本步骤。
5. 在显示 durable 保存后重启隔离应用，逐字核验内容、列表起始编号、选区/焦点行为；磁盘写入失败时确认窗口仍开且状态不是“已保存”。

## UI-01 指针、键盘、焦点与辅助技术（M/N）

1. 用 `all-modules-hidden-and-duplicate-ids.json` 测模块折叠、隐藏/显示与相同标题条目定位；确认内容保留并按稳定 ID 区分。
2. 拖动跨页长经历、模块和条目；覆盖快速松手、按 Escape 取消、拖回原位、边缘自动滚动及列表边界。记录最终顺序和 durable cursor。
3. 通过 Tab/Shift+Tab、Enter、Escape 和外部点击验证弹层焦点循环、关闭后焦点恢复、空模块可达和预览条目定位；缩放/分栏变化后复测。
4. 在真实辅助技术环境听取简历阅读顺序、链接名称与重复文本；确认视觉 SVG 与语义层没有重复朗读。记录辅助技术/版本、操作人和观察，不以 DOM snapshot 冒充。
5. 启用系统减少动态效果，打断折叠/拖动动画并快速切换；确认动画终态和正文内容一致。

## NATIVE-01 真实 WebView2 与数据边界（N/D）

1. 任何原生磁盘场景都设置全新的绝对路径 `ZINECV_DATA_DIR`，以 `fixtures/remaining` 合成文件填充；运行前后记录目标目录清单和哈希。
2. 新 profile 启动、编辑、重启恢复、备份/恢复、取消文件对话框、中文路径、无权限/空间不足和窗口关闭失败各记独立案例。
3. 迁移只用合成导出包；先 inspect/dryRun，再人工检查计数、字段和资源引用，确认后写入独立测试库。源包 SHA-256 前后必须一致。
4. 保留当前范围内的本机安装、升级及数据库兼容回退验证，使用隔离合成数据并记录实际安装包；干净VM/外部测试机和签名场景已取消，不以裸exe或mock冒充已执行的安装行为。

## IMPORT-01 PDF / DOCX / OCR 审阅

1. 在 R16/R17 生成的虚构文件语料目录中选取文本 PDF、扫描/旋转 PDF、DOCX 表格/浮图和中英 OCR 样本；记录文件 SHA-256、字节数、页数及像素限额。
2. 运行解析但不确认，检查候选字段、段落顺序、原图覆盖、置信度、unsupportedFeatures 和警告；任何失败、取消或超限均不得改变当前文档。
3. 人工修正一处候选后显式确认；验证目标 cursor 未变化、所有资源与文档一次性 durable 写入，再重启读取。
4. 复跑相同来源检查幂等和取消；源文件字节必须不变。低置信度、加密或损坏文件不得静默补值。

## VERSION-01 模板、历史与分支图

1. 用 `layout-matrix.json` 的 9 种模板/density组合确认版式切换只变 presentation；改名、收藏、最近使用和删除后重启读回。
2. 使用 `version-graph-1000.json` 验列表与树同源、中心缩放、拖动、键盘、焦点和空状态；UI吞吐与 SQLite 提交吞吐分开报告。
3. 在独立库执行提交、建分支、切换前确认/取消、载入历史、删除重接、默认分支保护和版本库恢复；只载入历史时草稿改变而 head 不动。
4. 双窗口用同一 cursor 竞争；冲突需显示最新状态，不可覆盖较新草稿。删除模板后历史引用仍可重现。

## MIGRATION-01 合成数据迁移审阅

1. 逐项生成并核对 `migration-scenarios.json` 所列源包：全量旧 origin、仅版本 JSON、主库损坏但 backup 有效、同 ID 冲突、缺资源、未来 schema、损坏账户和不可解密秘密。
2. 每次从源 SHA-256 开始执行 inspect/dryRun，记录类别计数、关系与未知项；目标库在 dryRun 后保持字节不变。
3. 由审阅者选择来源 namespace 和冲突方案后再 commit；verify/receipt 必须逐类别对账，部分可恢复项不能标为完整成功。
4. 重复同一源三次、加一条历史提交再导入、升级 importer 再导入；不得按更新时间覆盖不同内容或重复创建整库实体。

## IDENTITY-01 本机账户与秘密状态

1. 使用 R18 合成旧 scrypt 账户测试注册、错误密码限流、登录、登出、重启和匿名离线编辑；不复制真实账户数据。
2. 使用一次性测试 Key 验证保存后界面不能读回，Rust 仅在当前账户请求时解密；更新、删除、失效和切账户均检查旧会话/迟到响应。
3. 用受控不可解密密文模拟换 Windows 用户/机器恢复；配置和密文留存并提示重新输入，不把它报告为“连接不存在”。

## AGENT-01 三形态、会话、引用与本地技能

1. 在 Bot、composer 和 chat 三种形态启动同一个虚构 run；切换工作区、缩小/拖动浮层后继续，确认 target 与 sessionId 不变。
2. 选择姓名和一条同名经历中的单个稳定 ID；请求内容不得包含未选联系方式或整份版本历史。切换账户后旧 run 和消息不可见。
3. 无模型时运行只读版本比较/本地帮助，确认不改草稿；未知工具应拒绝并留下诊断。
4. 页面刷新或重启读取已保存会话；强杀遗留 running run 显示 interrupted，不能自动重放工具。

## PROPOSAL-01 用户确认、冲突和撤回

1. 让 fixture provider 返回两条待审建议，检查 account/document/context/branch/head/revision、beforeValues、scope 和解释；模型返回本身不能写入正文。
2. 拒绝建议、过期 cursor、第二条非法、跨账户、重复确认和确认/取消竞争均验证整组不落库或返回原 receipt。
3. 确认后重启读回；先手工修改同一字段再撤回，逆操作必须报告冲突并保留手工值。
4. 取消后注入迟到 chunk/tool/proposal；确认不会触发写命令，6 模型调用/12 工具调用/90 秒预算用合成时钟覆盖。

## REAL-MODEL-01 已授权真实模型（用户自行验收）

本节由用户自行执行和记录；Agent不再索取连接、代跑或等待配置，结果未提供时不记为通过。

1. 只在用户已明确配置 connectionId 后使用纯虚构简历；记录供应商、模型、structured 能力状态和时间，不记录 Key 或不必要的回答原文。
2. 验证正常聊天、SSE 拆分/取消、结构化建议、用户审阅、确认保存、重启读回、before 冲突和撤回冲突。
3. 未配置真实凭据时保持该项 blocked；本地模拟服务只证明适配开发行为。

## MOTION-01 减少动态效果

1. 分别在系统减少动态效果关闭/开启时进入、退出折叠、拖动条目并快速反向操作；记录动画终态、时长和是否残留遮挡。
2. 运动中切页、关闭弹层、调整分栏或取消拖动后，焦点与正文应处于稳定状态；任何系统级设置只由验收者临时切换并恢复。

## FILE-01 原生文件与失败反馈

1. 保存 PDF/PNG 时取消原生对话框，确认没有新文件或覆盖；以中文路径保存成功后独立提取文本/页数。
2. 使用受控只读目标、占用文件和小型受限卷模拟权限/占用/空间不足；记录真实错误状态，不伪造磁盘满结果。
3. 多页长图覆盖高 DPI、序号、尺寸、取消和像素上限；失败不得残留可被误认作完整输出的半文件。

干净VM/外部测试机及Authenticode/更新签名要求已于2026-10-21取消。以下保留产品行为检查，不等待专用机器或证书。

1. 在可用本机环境、隔离合成数据与获准安装路径下核对实际安装包，记录包hash、环境和退出码；不宣称完成未执行的干净机器场景。
2. 验证升级前备份、升级后草稿/版本/设置保留及卸载默认留数据；涉及用户真实数据的操作不在测试中执行。
3. 兼容回退使用匹配schema的隔离数据库副本；权限、中文路径、空间不足等场景记录实际覆盖和未覆盖范围。

## LICENSE-01 资源许可与分发

来源配置以`docs/resource-licenses.json`为准，当前盘点用`verify:licenses`；摘要描述本次输入，来源不同、不可用或远程未核对须审核，不把命令退出0视为授权通过。

1. 对字体、图标、模板、OCR 模型/WASM、PDF CMap 与原生依赖逐一记录文件名、来源、版本、SHA-256、许可证正文和分发方式。
2. 区分使用许可与再分发许可；字体转换不改变许可。授权不明的资源不可标为公开分发通过，也不得为了通过而擅换纸面字体。

## RELEASE-01 可搜索 PDF

1. 从冻结 revision 导出一页、两页、五页和富文本夹具 PDF；记录 SHA-256、页数和 A4 页面尺寸。
2. 使用独立 PDF 文本提取工具检查中英文搜索/复制、链接、列表阅读顺序和字体嵌入；确认 PDF 是文本输出，overlay 不进入文件。
3. 预览期间继续编辑后完成导出，导出文件必须仍对应调用开始时冻结的 cursor 与资源。
