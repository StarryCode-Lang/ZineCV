# ZineCV 桌面版（zinecv-desktop）

Tauri 2 + React + Rust/Typst 引擎 + SQLite 的本地简历编辑器。P00–P17 功能实现已落地；当前正式预览保持现有 DOM 版。**项目现状、验证边界和待验收项以 `docs/SLICE_20261002.md` 为唯一权威切片**。

## 主链路与目录

```text
src/main-desktop.tsx → src/ui/app/App.tsx → src/platform/ipc.ts
                                        → src-tauri/src/lib.rs
                                          ├─ domain.rs / storage.rs / migration.rs
                                          └─ render_worker.rs / engine.rs / engine/
```

| 目录 | 职责 |
| --- | --- |
| `src/ui/` | 正式 React 工作区：编辑、DOM 预览、模板、版本、Agent 与样式 |
| `src/platform/` | 前端宿主边界：IPC、文档转换、持久化、设置和旧数据导入 |
| `src/preview/` | 已实现但尚未切为默认 UI 的引擎 SVG 预览与选区 |
| `src-tauri/src/` | Tauri 命令、领域规则、SQLite、身份与迁移 |
| `src-tauri/src/engine/` | Typst 排版、TextMap、一页求解与统一导出 |

`src-tauri/src/domain/bindings/` 是 Rust 生成的 IPC 类型，不手改。引擎 SVG 切默认预览仍受字体与几何验收门禁约束。

## 构建（三步）

1. `npm ci` —— 安装锁定依赖（Node ≥ 24，Rust ≥ 1.88）。
2. `npm run build:native` —— Vite 产出 `dist/` + cargo release；cargo/clippy/test 必须经 `tools/with-msvc.ps1` 封装（npm 脚本已包含），直接调用 cargo 会在 MSVC 链接阶段失败。
3. `npm run package:windows` —— 生成在线 NSIS 安装包（`src-tauri/target/release/bundle/nsis/`）；离线包加 `-- --config src-tauri/tauri.conf.offline.json`。

日常开发预览：`npm run dev`。

## 清理边界

`dist/`、`src-tauri/target/`、`src-tauri/gen/`、`src-tauri/permissions/autogenerated/`、`.gitnexus/` 和 `.artifacts/` 下的运行期目录（`webview-e2e`、`runtime-tmp`、`analysis`、`audit`、测试残留的 `*-profile-*`）均为可再生输出。`.artifacts/remaining/` 存放矩阵引用的验收证据，不能整体删除。

构建产物按大版本保留一代：本次轻量化后 `src-tauri/target/` 只保留 `release`（exe + PDB + NSIS 安装包）；测试档 `debug`（约 16.1 GiB）与 `hooks`（约 3.4 GiB）已剪枝，重建代价分别约 7 分钟与 6 分钟。
